Rawcookr 사용 설명서

사진을 현상하고, 사람을 가리고, 원하는 색을 입혀 바로 올릴 수 있게 내보내기까지. 모든 기능을 항목별로 정리했습니다.

macOS 14 이상 · 버전 1.1 기준

화면 구성

Rawcookr에는 화면이 두 개 있습니다.

라이브러리

폴더를 고르고 사진을 훑어보는 곳입니다. 왼쪽에 폴더 목록, 가운데에 썸네일 격자가 있습니다. 여기서 별점과 깃발을 매기고, 여러 장을 골라 한꺼번에 내보냅니다.

마운트

사진 여러 장을 한 판에 얹어 한 장으로 묶는 곳입니다. 자세한 것은 판에 사진 올리기를 보세요.

현상

사진 한 장을 실제로 손보는 곳입니다. 가운데에 사진, 오른쪽에 조정 항목 패널, 아래에 필름스트립이 놓입니다. 라이브러리에서 사진을 두 번 누르거나 Return 을 누르면 들어갑니다. 돌아올 때는 Esc 입니다.

화면을 넓게 쓰고 싶을 때

필름스트립은 ⌘F 로 감출 수 있고, 사진만 전체화면으로 보려면 ⌃⌘F 를 누릅니다. 오른쪽 패널의 항목을 전부 접으려면 ., 전부 펼치려면 , 입니다.

사진 불러오기

폴더 열기

파일 → 폴더 열기(⌘O)로 사진이 든 폴더를 고릅니다. 한 번 고른 폴더는 왼쪽 사이드바에 남아 다음에 열 때 바로 누를 수 있습니다. 사이드바에서 지우려면 폴더 이름을 오른쪽 눌러 사이드바에서 제거를 고릅니다. 폴더 안의 하위 폴더도 함께 나열됩니다.

Finder에서 바로 열기

Finder에서 사진 파일을 오른쪽 눌러 다음으로 열기 → Rawcookr 를 고르면, 그 파일이 든 폴더가 라이브러리에 추가되고 곧바로 현상 화면이 열립니다.

원본은 그대로 둡니다

Rawcookr는 원본 파일에 절대 쓰지 않습니다. 편집한 값은 작은 설정 파일에 따로 적힙니다. 원본을 다른 앱으로 열면 손대기 전 그대로입니다.

설정을 어디에 둘지는 환경설정에서 고릅니다.

선택뜻
앱 폴더에서 관리 기본원본 폴더가 깨끗하게 유지됩니다. 사진 폴더를 그대로 남에게 넘길 때 편합니다.
원본 파일 옆에사진과 설정이 늘 붙어 다닙니다. 외장 디스크째로 다른 Mac에 옮겨도 편집이 따라옵니다.

편집 내용을 파일로 뽑아 두거나 다시 읽어 들일 수도 있습니다. 현상 화면에서 설정 저장·설정 적용을 쓰면 .rawcookr-settings.json 파일로 오갑니다.

구독 관리와 해지는 App Store 계정 설정에서 합니다. 체험 기간이 끝나기 전에 해지하면 요금이 청구되지 않습니다.

폴더와 썸네일

라이브러리에서는 폴더 하나가 한 화면입니다. 왼쪽 사이드바에서 폴더를 고르면 그 안의 사진이 격자로 깔립니다.

훑어보기

  • 썸네일 크기는 오른쪽 위 슬라이더로 바꿉니다.
  • 화살표 키로 사진 사이를 옮겨 다닙니다.
  • Return 으로 현상 화면에 들어갑니다.
  • Space 는 크게 보기입니다. 한 번 더 누르거나 Esc 로 닫고, 크게 본 상태에서 Return 을 누르면 그 사진을 현상합니다. 아래에 파일 이름이 함께 뜹니다.

고르기

  • 클릭으로 한 장, ⇧+클릭으로 범위, ⌘+클릭으로 하나씩 더하기.
  • 빈 곳에서 드래그하면 사각형으로 여러 장을 한 번에 고릅니다.
  • ⌘A 로 전부 고릅니다.

많이 찍은 날 쓸 만한 것만 골라내는 데 씁니다. 라이브러리와 현상 화면 어디서든 매길 수 있습니다.

라이브러리에서는 고른 사진 전부에 한 번에 들어갑니다. 매긴 뒤에는 화면 위쪽 필터로 깃발만 또는 별점 이상만 남겨 볼 수 있습니다. 별점과 깃발도 편집값과 같은 곳에 저장되므로 원본 파일은 그대로입니다.

여러 장 한꺼번에

편집 옮기기

한 장을 마음에 들게 맞췄다면 그 값을 다른 사진에 그대로 옮길 수 있습니다.

  1. 기준이 될 사진에서 ⌘⇧C — 편집 내용 복사
  2. 적용할 사진을 고르고 ⌘⇧V — 편집 내용 붙여넣기

붙여넣기는 지금 열려 있는 한 장에만 들어갑니다. 여러 장에 옮기려면 → 로 다음 사진으로 넘어가 ⌘⇧V 를 다시 누르세요.

자리에 매인 항목 — 개인정보 블러 영역, 색수차 브러시 자국, 자른 자리, 부분 보정 마스크 — 은 옮겨지지 않고 받는 사진의 것이 그대로 남습니다. 사진마다 얼굴 위치가 다르니 그 편이 맞습니다.

한꺼번에 내보내기

고른 사진이 여러 장인 상태에서 ⌘E 를 누르면 전부 같은 설정으로 내보냅니다. 자세한 것은 내보내기를 보세요.

주의

편집 붙여넣기는 되돌리기가 없습니다. 여러 장에 한꺼번에 넣기 전에 한 장으로 먼저 확인해 보시는 편이 안전합니다.

버전

같은 사진을 다르게 현상해 두고 나란히 비교하고 싶을 때 씁니다. 파일을 복사하지 않기 때문에 디스크를 한 바이트도 더 쓰지 않습니다.

현상 화면에서 파일 → 새 버전으로 현상(⌘G)을 고르면, 지금 편집은 그대로 둔 채 손대지 않은 사본이 하나 더 생깁니다. 필름스트립에 V2, V3 처럼 번호가 붙어 나타납니다.

버전을 지워도 원본 파일은 남습니다. 지우려 할 때 "원본 파일은 그대로 둡니다"라고 알려 주는 것이 그 뜻입니다.

원본 비교와 클리핑 경고

원본 보기 M

누르고 있는 동안 편집 전 상태가 나옵니다. 손댄 것이 실제로 나아졌는지 확인하는 가장 빠른 방법입니다.

클리핑 경고 J

완전히 하얗게 날아간 곳은 빨강, 완전히 검게 뭉갠 곳은 파랑으로 덮어 보여 줍니다.

한 채널만 끝에 닿은 정도 — 예를 들어 새빨간 꽃잎 — 는 아직 색이 남아 있으므로 경고하지 않습니다. 세 채널이 모두 끝에 닿아 정보가 실제로 사라진 곳만 표시합니다. 화면 위에 클리핑 알림이 떴다면 눌러서 바로 경고 표시를 켜고 끌 수 있습니다.

히스토그램

오른쪽 패널의 히스토그램은 밝기 분포를 보여 줍니다. 왼쪽 끝에 붙으면 어두운 쪽이, 오른쪽 끝에 붙으면 밝은 쪽이 잘리고 있다는 뜻입니다.

비교 보기

사진 두 장을 나란히 놓고 보는 기능입니다. 같은 장면을 다르게 현상한 것 중 어느 쪽이 나은지 고를 때, 또는 버전끼리 견줄 때 씁니다.

  1. 도구 막대의 비교 를 누릅니다.
  2. 왼쪽에 지금 사진이 놓이고, 오른쪽에 견줄 사진을 고릅니다.
  3. 배율을 맞춰 두면 두 쪽이 같이 움직여 같은 부분을 같은 크기로 볼 수 있습니다.

조정 항목 다루기

오른쪽 패널은 항목(섹션)으로 나뉘어 있습니다. 각 항목은 접고 펼칠 수 있고, 순서도 바꿀 수 있습니다.

되돌리기

프리셋

지금 사진에 들어간 모든 편집값을 통째로 저장해 두고, 다른 사진에 한 번에 씌우는 기능입니다. 필름과 톤, 부분 보정까지 전부 포함됩니다.

만들기

  1. 사진 한 장을 원하는 대로 맞춥니다.
  2. 프리셋 항목의 + 를 누르고 이름을 적습니다.
  3. 같은 이름으로 다시 저장하면 덮어씁니다.

쓰기

프리셋 목록에는 지금 열려 있는 사진에 각 프리셋을 씌운 모습이 작은 그림으로 나옵니다. 눌러 보면 바로 적용됩니다. 썸네일 크기는 아주 작게 · 작게 · 크게 중에서 고릅니다.

프리셋과 필름의 차이

필름은 색 변환 하나입니다. 프리셋은 필름을 포함한 편집 전체입니다. "이 색감"만 재사용하려면 필름을, "이 사진을 만든 방식 전부"를 재사용하려면 프리셋을 쓰세요.

나만의 필름 만들기

필름 목록에 자기 것을 더하는 방법은 두 가지입니다.

둘 다 필름 레시피 항목에서 커스텀 계열을 고르면 나오는 메뉴에 있습니다.

가지고 있는 LUT을 필름으로

  1. 커스텀 계열 메뉴에서 LUT to FILM… 을 누릅니다.
  2. .cube 파일을 고릅니다.
  3. 이름을 붙이면 필름 목록에 들어갑니다.

흑백 LUT은 흑백 필름으로 자동 인식되어, 단색화 WC·MG 같은 흑백 전용 조정값이 나옵니다.

맞춘 색을 필름으로

톤 커브·HSL·색상 균형으로 마음에 드는 색을 만들었다면, 같은 메뉴의 색상을 필름으로… 로 그 색 변환만 떼어 저장합니다.

만든 필름은 필름을 LUT로 내보내기 로 .cube 파일을 뽑을 수 있습니다. 다른 앱에서도 쓸 수 있습니다.

레시피북으로 묶어서 나누기

만든 필름과 프리셋을 .rawb 파일 하나로 묶습니다. 파일을 받은 사람은 레시피북 불러오기 한 번으로 전부 가져갑니다.

같은 장비를 쓰는 사람들끼리 색감을 나누거나, Mac을 바꿀 때 설정을 통째로 옮기는 데 씁니다.

자주 겪는 일

RAW 파일이 열리지 않습니다

RAW 현상은 macOS에 내장된 엔진을 씁니다. 아주 최근에 나온 기종은 macOS가 업데이트되어야 지원됩니다. 시스템 설정 → 일반 → 소프트웨어 업데이트를 확인해 보세요. 그래도 열리지 않으면 카메라에서 DNG로 저장해 보시거나 알려 주세요.

썸네일이 느리게 뜹니다

처음 여는 폴더에서는 사진마다 미리보기를 만들어야 해서 시간이 걸립니다. 한 번 만든 뒤로는 빨라집니다. 사진이 아주 많은 폴더라면 하위 폴더로 나누는 편이 쾌적합니다.

선명함이나 입자가 적용되지 않은 것 같습니다

화면에 맞춘 배율에서는 사진을 줄여 그리기 때문에 픽셀 단위 효과가 보이지 않습니다. ⌘1 로 100%에 놓고 확인하세요.

편집이 사라졌습니다

편집값은 원본과 별개의 파일에 있습니다. 저장 위치를 원본 파일 옆에 로 쓰고 있었다면, 사진만 다른 곳으로 옮길 때 설정 파일이 따라오지 않았을 수 있습니다. 앱 안에서 다른 폴더로 이동을 쓰면 설정도 함께 옮겨집니다.

구독이 인식되지 않습니다

App Store에 같은 Apple 계정으로 로그인되어 있는지 확인한 뒤, 구독 화면의 구매 복원을 눌러 보세요.

가린 얼굴이 남아 있습니다

자동 검출은 옆얼굴·마스크·어두운 곳의 얼굴을 놓칠 수 있습니다. 직접 영역을 그려 넣어 보완하시고, 공개 전에 100%로 한 번 훑어보세요.

마운트 작업이 사라졌습니다

마운트는 저장하기 전까지 파일로 남지 않습니다. ⌘S 로 먼저 저장해 두세요. 저장하지 않은 채 탭을 옮기거나 앱을 끄려 하면 물어봅니다.
